AI Analysis

The ablation results indicate that the global encoding token is the most critical component, as its removal (Condition E) causes a significant drop in retrieval accuracy at 180° compared to the full model (A). Furthermore, the reliance on rich feature representations is evident, since restricting the model to XYZ coordinates only (Condition D) severely degrades performance, particularly under large rotations. While standard data augmentation strategies like SO3 (Condition B) offer modest improvements, they fail to match the robustness of the full RISA architecture, whereas TTA (Condition C) proves ineffective for this task. Overall, the study reveals that global context aggregation and comprehensive feature utilization are far more impactful for rotation-invariant retrieval than simple geometric augmentations or test-time strategies.

AI Analysis

The `perceiver` flag determines whether the model uses a Perceiver-style architecture with a fixed set of latent queries to compress the variable-sized point cloud into a constant-length representation, or relies on a standard transformer that processes all points directly. The non-perceiver variant likely transfers better because it preserves the full geometric detail of the input without the information bottleneck inherent in the latent compression step, allowing it to retain more discriminative local features that are critical for generalizing from the synthetic ModelNet40 to the real-world, noisy ScanObjectNN dataset.
