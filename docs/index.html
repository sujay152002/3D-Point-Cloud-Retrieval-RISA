Analysis

The `perceiver` flag determines whether the model uses a Perceiver architecture, which employs a fixed set of latent arrays to compress and process variable-length point clouds, versus a standard transformer that attends directly over all input points. The variant with `perceiver=False` transfers better because direct attention mechanisms preserve more granular geometric details and local structural nuances, which are critical for distinguishing specific object categories across the significant domain gap between synthetic (ModelNet40) and real-world (ScanObjectNN) data. In contrast, the Perceiver's aggressive compression into a small number of latent vectors may discard fine-grained features necessary for robust cross-dataset generalization.
